Clothing POS

คู่มือติดตั้งและเริ่มใช้งาน · สำหรับคอมพิวเตอร์หน้าร้าน

1สิ่งที่ต้องมี

  • คอมพิวเตอร์ Windows 10 หรือ 11 (64-bit) ที่ต่ออินเทอร์เน็ต (แนะนำให้มีเน็ต 4G สำรองที่ร้าน)
  • เครื่องพิมพ์ใบเสร็จที่ ติดตั้งไดรเวอร์ใน Windows แล้ว (USB / LAN / Bluetooth) — กระดาษ 58 หรือ 80 มม.
  • PIN พนักงานของสาขา (ขอจากผู้จัดการร้าน)

2ติดตั้งโปรแกรม

  1. แตกไฟล์ zip แล้วดับเบิลคลิก ClothingPOS-Setup-x.x.x.exe
  2. ถ้า Windows ขึ้น "Windows protected your PC" ให้กด More info → Run anyway
  3. เลือกโฟลเดอร์ติดตั้ง (ใช้ค่าเดิมได้) → Install → Finish
  4. จะมีไอคอน Clothing POS บนเดสก์ท็อป และในเมนู Start
คำเตือนจาก Windows ขึ้นเพราะโปรแกรมนี้ใช้ภายในร้าน ยังไม่ได้ซื้อใบรับรองดิจิทัล — ขึ้นเฉพาะครั้งแรก การอัปเดตครั้งต่อไปไม่ถาม

3ตั้งค่าเครื่องพิมพ์ (ทำครั้งเดียวต่อเครื่อง)

  1. เปิดโปรแกรม → เมนู ระบบ → ตั้งค่าเครื่องนี้ (หรือกด Ctrl + ,)
  2. วิธีพิมพ์ — ESC/POS แบบรูปภาพ (แนะนำ สำหรับเครื่องพิมพ์ใบเสร็จทั่วไป)
  3. การเชื่อมต่อ — USB แล้วเลือกเครื่องพิมพ์ใบเสร็จ หรือ LAN / WiFi แล้วใส่ IP ของเครื่องพิมพ์
  4. ขนาดกระดาษ — ตามตั้งค่าร้าน หรือเลือก 58 มม. / 80 มม. ให้ตรงกับม้วนกระดาษจริง
  5. ตัดกระดาษ และ เปิดลิ้นชักเงิน (ไม่เปิด / ขายด้วยเงินสด / ทุกการขาย) ตามอุปกรณ์ของร้าน
  6. กด พิมพ์ทดสอบ — แถบดำและคำว่า |ซ้าย · กลาง · ขวา| ต้องอยู่ในกระดาษครบ → บันทึก

4เริ่มขาย

  1. ใส่ PIN 6 หลัก ของพนักงาน — ระบบเปิดสาขาที่พนักงานคนนั้นดูแล (ดูชื่อสาขาที่มุมซ้ายบน)
  2. ครั้งแรกของวันระบบจะให้ เปิดกะ และนับเงินตั้งต้นในลิ้นชัก
  3. สแกนหรือเลือกสินค้า → ชำระเงิน → ใบเสร็จพิมพ์ออกเครื่องพิมพ์ทันที
  4. เลิกงาน: กด ปิดกะทำงาน นับเงิน แล้วพิมพ์สรุปยอดประจำวัน

5การอัปเดตโปรแกรม

ดาวน์โหลดเอง

เมื่อมีเวอร์ชันใหม่ มุมขวาบนจะแสดง "ดาวน์โหลด vX.Y.Z · %" — ขายต่อได้ตามปกติ

ปุ่มสีเขียว "อัปเดต"

กดเมื่อไม่มีลูกค้า → อัปเดตตอนนี้ โปรแกรมปิดและเปิดใหม่เอง (10–30 วินาที)

ถ้ากด ภายหลัง ระบบจะติดตั้งให้ตอนปิดโปรแกรม · รายการในตะกร้าที่ยังไม่ชำระเงินจะหายเมื่ออัปเดต · ดูเวอร์ชันที่ติดตั้งได้ที่ท้ายเมนูซ้าย ("แอป x.x.x")

6แก้ปัญหาเบื้องต้น

อาการวิธีแก้
ขึ้น "เชื่อมต่อเซิร์ฟเวอร์ไม่ได้"ตรวจอินเทอร์เน็ตของร้าน หรือสลับไปใช้ 4G สำรอง — โปรแกรมลองเชื่อมต่อใหม่เองทุก 10 วินาที
กดพิมพ์แล้วไม่ออกตรวจว่าเครื่องพิมพ์เปิดอยู่และมีกระดาษ → ตั้งค่าเครื่องนี้ เลือกเครื่องพิมพ์ใหม่ → พิมพ์ทดสอบ
ขอบขวาหาย / ตัวหนังสือตกขอบเลือกขนาดกระดาษให้ตรงม้วนจริง แล้วลด ความกว้างพิมพ์ ทีละ 8 จุด (เช่น 576 → 560)
พิมพ์จาง / ทึบเกินปรับ ความเข้ม ในตั้งค่าเครื่องนี้ แล้วพิมพ์ทดสอบ
ลิ้นชักเงินไม่เปิดกด ทดสอบเปิดลิ้นชัก ถ้าไม่เปิด ลองเปลี่ยน ขาสัญญาณ เป็นขา 5
ลืม PINให้ผู้จัดการร้านตั้ง PIN ใหม่ในเมนู พนักงาน
หน้าจอค้าง / แสดงผลแปลกกด F5 เพื่อโหลดหน้าใหม่ ถ้ายังไม่หาย ปิดแล้วเปิดโปรแกรมใหม่
สำหรับพนักงานร้านเท่านั้น — ห้ามส่งต่อไฟล์ติดตั้ง ลิงก์ดาวน์โหลด รหัสผ่าน หรือ PIN ให้บุคคลภายนอก
