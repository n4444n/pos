# แอปเดสก์ท็อป Clothing POS (.exe)

แอปนี้เป็น **เครื่องลูก**: เปิดหน้า POS จากเซิร์ฟเวอร์กลาง `https://pos.sh0p.tech`
ตัวติดตั้งเดียวใช้ได้ทุกร้าน — เปิดครั้งแรกให้กรอก license (ดู `deploy/README.md` หัวข้อ "ทุกร้านหลังโดเมนเดียว")
ไม่มีฐานข้อมูลในเครื่อง ทุกสาขา (กรุงเทพ / ภูเก็ต / สมุย) เห็นรายการสินค้าเดียวกัน ส่วนสต็อก/ยอดขายแยกตามสาขาที่พนักงานเข้าสู่ระบบ

| ทำได้ | หมายเหตุ |
|---|---|
| พิมพ์ใบเสร็จ / รายงานปิดกะ / สรุปยอดประจำวัน ทันที | ไม่ขึ้นกล่องเลือกเครื่องพิมพ์ · ความยาวกระดาษตามเนื้อหา |
| เลือกเครื่องพิมพ์ + กระดาษ 58/80 มม. ต่อเครื่อง | เมนู **ระบบ → ตั้งค่าเครื่องนี้** (Ctrl+,) |
| แจ้งเตือนอัปเดต | ตรวจตอนเปิดโปรแกรม และทุก 4 ชั่วโมง · ขึ้นปุ่มสีเขียว **"อัปเดต vX.Y.Z"** ในหน้าโปรแกรม (ตั้งแต่ 1.0.1) |
| เน็ตหลุด | ขึ้นหน้า "เชื่อมต่อไม่ได้" และลองใหม่เองทุก 10 วินาที |

ใบส่งสินค้า (A4) ยังเปิดหน้าตัวอย่าง แล้วกดพิมพ์เลือกเครื่องพิมพ์ A4 ตามปกติ

## ไฟล์ zip สำหรับแจกให้ร้าน
หน้า `https://pos.sh0p.tech/download/` ให้ดาวน์โหลด `ClothingPOS-vX.Y.Z.zip` ซึ่งสร้างโดย GitHub Actions:
- ตัวติดตั้ง `ClothingPOS-Setup-X.Y.Z.exe`
- **ทุกไฟล์ในโฟลเดอร์ `desktop/package-extras/`** — อยากเพิ่มไฟล์ (เช่น ไดรเวอร์เครื่องพิมพ์ คู่มือเพิ่ม) แค่วางไฟล์ในโฟลเดอร์นี้แล้ว push
  (ไม่ต้องเพิ่ม version — ระบบใช้ตัวติดตั้งเดิมแล้วแพ็ก zip ใหม่ให้)
- `Readme.pdf` = คู่มือติดตั้งและเริ่มใช้งาน · แก้ต้นฉบับที่ `desktop/readme/Readme.html` แล้วสร้าง PDF ใหม่
  (เปิดใน Chrome → พิมพ์ → บันทึกเป็น PDF · A4 · ปิดหัว/ท้ายกระดาษ · เปิดกราฟิกพื้นหลัง) วางทับ `desktop/package-extras/Readme.pdf`
- ชื่อไฟล์ใน `package-extras/` ควรเป็นภาษาอังกฤษ จะได้ไม่เพี้ยนบน Windows บางเครื่อง

## สร้างไฟล์ติดตั้ง
GitHub Actions build ให้อัตโนมัติ (`.github/workflows/desktop-release.yml`) — ดู `deploy/README.md` หัวข้อ "สร้างตัวติดตั้งอัตโนมัติ"
1. แก้ไฟล์ใน `desktop/` แล้ว **เพิ่ม `"version"`** ใน `desktop/package.json` (เช่น 1.0.1 → 1.0.2)
2. push ขึ้น main → รอ ~10 นาที (ดูสถานะในแท็บ Actions)
3. ได้ตัวติดตั้งบน VPS (`/updates/` สำหรับอัปเดตอัตโนมัติ) + zip ใหม่ที่ `https://pos.sh0p.tech/download/`

## ติดตั้งที่สาขา
1. ดาวน์โหลด zip จาก `https://pos.sh0p.tech/download/` (ชื่อผู้ใช้ `shop`) แตกไฟล์ แล้วเปิด `ClothingPOS-Setup-x.x.x.exe`
   - ไฟล์ยังไม่มีลายเซ็นดิจิทัล Windows จะเตือน "Windows protected your PC" → **More info → Run anyway** (ครั้งแรกครั้งเดียว อัปเดตต่อไปไม่ถาม)
2. เปิดโปรแกรม → **ระบบ → ตั้งค่าเครื่องนี้** (ดูหัวข้อ "เครื่องพิมพ์ใบเสร็จ" ด้านล่าง) → **พิมพ์ทดสอบ** → **บันทึก**
3. เข้าสู่ระบบด้วย PIN ของพนักงานสาขานั้น

## เครื่องพิมพ์ใบเสร็จ
| วิธีพิมพ์ | ใช้เมื่อ |
|---|---|
| **ESC/POS แบบรูปภาพ** (แนะนำ · ค่าเริ่มต้นเครื่องใหม่) | เครื่องพิมพ์ใบเสร็จทั่วไป (Xprinter, GPrinter, Epson TM, Sunmi …) — ส่งใบเสร็จเป็นรูปตรงเข้าเครื่องพิมพ์: ภาษาไทยถูกทุกตัว · ตัดกระดาษ · เปิดลิ้นชักเงิน · ไม่ต้องตั้งค่าไดรเวอร์ |
| **ผ่านไดรเวอร์ Windows** (แบบเดิม) | เครื่องพิมพ์ที่ไม่รองรับ ESC/POS · เครื่องที่ตั้งค่าไว้ก่อนแอป 1.0.4 จะใช้แบบนี้ต่อจนกว่าจะเปลี่ยนเอง |

ตั้งค่าได้ 2 ที่ (ค่าเดียวกัน เก็บในเครื่องนี้): ในระบบ **ตั้งค่า → ตั้งค่าเครื่องพิมพ์ใบเสร็จ** (ผู้จัดการ) หรือเมนูแอป **ระบบ → ตั้งค่าเครื่องนี้** (Ctrl+,)

ESC/POS ตั้งค่าได้: การเชื่อมต่อ **USB** (เลือกเครื่องพิมพ์ใน Windows) · **LAN/WiFi** (IP + พอร์ต 9100) · **Bluetooth** (จับคู่ใน Windows ก่อน → เลือกพอร์ต COM เสมือน เช่น COM5 · ใช้กับสาย Serial ได้ด้วย) · กระดาษ 58/80 มม. · ความกว้างพิมพ์ (จุด: 0 = อัตโนมัติ 384/576) · ความเข้ม · เว้นหัว/ท้าย · ตัดกระดาษ · เปิดลิ้นชัก (ไม่เปิด / ขายด้วยเงินสด / ทุกการขาย — เปิดตอนขายเสร็จ ไม่เปิดตอนพิมพ์ซ้ำ) · ปุ่ม **ดูตัวอย่าง** แสดงภาพที่จะส่งเข้าเครื่องพิมพ์

| อาการ | แก้ |
|---|---|
| ขอบขวาหาย | ลดความกว้างพิมพ์ทีละ 8 จุด (เช่น 576 → 560, 384 → 368) |
| ตัวหนังสือจาง / ทึบเกิน | ปรับความเข้ม (มาก = เข้ม) |
| ลิ้นชักไม่เปิด | กด "ทดสอบเปิดลิ้นชัก" · ลองเปลี่ยนขาสัญญาณ 2 ↔ 5 |
| USB: "ส่งงานพิมพ์ไม่สำเร็จ" | ตรวจว่าเลือกชื่อเครื่องพิมพ์ใบเสร็จ (ไม่ใช่ Microsoft Print to PDF) และเครื่องเปิดอยู่ |

## ส่งอัปเดตให้ทุกสาขา
1. เพิ่ม `"version"` ใน `desktop/package.json` → push ขึ้น main (GitHub Actions ส่งขึ้น VPS ให้)
2. ทุกเครื่องจะดาวน์โหลดเบื้องหลัง (มุมขวาบนแสดง "ดาวน์โหลด vX.Y.Z · %")
   เสร็จแล้วขึ้นปุ่มสีเขียว **"อัปเดต vX.Y.Z"** ที่แถบด้านบนหน้าขาย และในเมนูด้านซ้าย
   กดปุ่ม → หน้าต่างแสดงเวอร์ชันเก่า → ใหม่ → **อัปเดตตอนนี้** (โปรแกรมปิดแล้วเปิดใหม่เอง) หรือ **ภายหลัง**
   ไม่กดเลย = ติดตั้งให้ตอนปิดโปรแกรม · ไม่ขัดการขายที่ทำอยู่
   เวอร์ชันแอปที่ติดตั้งอยู่ดูได้ที่ท้ายเมนูซ้าย ("แอป 1.0.1")

> ส่วนใหญ่ **ไม่ต้องออกเวอร์ชันแอปใหม่**: หน้าจอ ฟีเจอร์ รายงาน มาจากเซิร์ฟเวอร์ → `pos-update` บน VPS ทุกสาขาได้ทันที
> ต้องออก .exe ใหม่เฉพาะเมื่อแก้ไฟล์ในโฟลเดอร์ `desktop/`

### บังคับอัปเดต (เฉพาะกรณีจำเป็น)
บน VPS:
```bash
echo '{"minVersion":"1.0.1","message":"แก้ปัญหาการพิมพ์ ต้องอัปเดตก่อนใช้งานต่อ"}' > /var/www/pos-updates/min-version.json
```
เครื่องที่เวอร์ชันต่ำกว่า `minVersion` จะไม่มีปุ่ม "ภายหลัง" — ติดตั้งทันทีที่ดาวน์โหลดเสร็จ
ยกเลิก: `rm /var/www/pos-updates/min-version.json`

## ทดลองระหว่างพัฒนา
```bat
cd desktop
npm install
npm start
```
โหมดนี้ไม่ตรวจอัปเดต · ตั้งค่าเครื่องอยู่ที่ `%APPDATA%\Clothing POS\config.json`
