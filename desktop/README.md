# แอปเดสก์ท็อป Clothing POS (.exe)

แอปนี้เป็น **เครื่องลูก**: เปิดหน้า POS จากเซิร์ฟเวอร์กลาง `https://pos.sh0p.tech`
ไม่มีฐานข้อมูลในเครื่อง ทุกสาขา (กรุงเทพ / ภูเก็ต / สมุย) เห็นรายการสินค้าเดียวกัน ส่วนสต็อก/ยอดขายแยกตามสาขาที่พนักงานเข้าสู่ระบบ

| ทำได้ | หมายเหตุ |
|---|---|
| พิมพ์ใบเสร็จ / รายงานปิดกะ / สรุปยอดประจำวัน ทันที | ไม่ขึ้นกล่องเลือกเครื่องพิมพ์ · ความยาวกระดาษตามเนื้อหา |
| เลือกเครื่องพิมพ์ + กระดาษ 58/80 มม. ต่อเครื่อง | เมนู **ระบบ → ตั้งค่าเครื่องนี้** (Ctrl+,) |
| แจ้งเตือนอัปเดต | ตรวจตอนเปิดโปรแกรม และทุก 4 ชั่วโมง · ขึ้นปุ่มสีเขียว **"อัปเดต vX.Y.Z"** ในหน้าโปรแกรม (ตั้งแต่ 1.0.1) |
| เน็ตหลุด | ขึ้นหน้า "เชื่อมต่อไม่ได้" และลองใหม่เองทุก 10 วินาที |

ใบส่งสินค้า (A4) ยังเปิดหน้าตัวอย่าง แล้วกดพิมพ์เลือกเครื่องพิมพ์ A4 ตามปกติ

## สร้างไฟล์ติดตั้ง
ต้องมี Node.js บนเครื่องที่ build (เครื่องพัฒนา ไม่ใช่เครื่องที่ร้าน)
1. แก้ `"version"` ใน `desktop/package.json` (ทุกครั้งที่ออกเวอร์ชันใหม่ ต้องเพิ่มเลข เช่น 1.0.0 → 1.0.1)
2. ดับเบิลคลิก `build-desktop.bat`
3. ได้ `desktop\release\ClothingPOS-Setup-<version>.exe` + `latest.yml` + `.blockmap`

## ติดตั้งที่สาขา
1. คัดลอก `ClothingPOS-Setup-x.x.x.exe` ไปที่เครื่องร้าน แล้วติดตั้ง
   - ไฟล์ยังไม่มีลายเซ็นดิจิทัล Windows จะเตือน "Windows protected your PC" → **More info → Run anyway** (ครั้งแรกครั้งเดียว อัปเดตต่อไปไม่ถาม)
2. เปิดโปรแกรม → **ระบบ → ตั้งค่าเครื่องนี้**
   - เลือกเครื่องพิมพ์ใบเสร็จ (ต้องติดตั้งไดรเวอร์ใน Windows ก่อน)
   - ขนาดกระดาษ: "ตามตั้งค่าร้าน" หรือ 58 / 80 มม.
   - กด **พิมพ์ทดสอบ** → ข้อความ "ซ้าย / กลาง / ขวา" ต้องอยู่ในกระดาษครบ
3. เข้าสู่ระบบด้วย PIN ของพนักงานสาขานั้น

ถ้าตัวหนังสือตกขอบ: ในคุณสมบัติไดรเวอร์เครื่องพิมพ์ (Windows → Printers → Printing preferences) ตั้งขนาดกระดาษให้ตรงกับม้วนจริง (เช่น 80 × Receipt / 72 มม. printable)

## ส่งอัปเดตให้ทุกสาขา
1. เพิ่ม `"version"` → `build-desktop.bat`
2. ดับเบิลคลิก `publish-update.bat` (อัปโหลดขึ้น `/var/www/pos-updates/` บน VPS ด้วย scp — ต้องเข้า SSH ได้)
3. ทุกเครื่องจะดาวน์โหลดเบื้องหลัง (มุมขวาบนแสดง "ดาวน์โหลด vX.Y.Z · %")
   เสร็จแล้วขึ้นปุ่มสีเขียว **"อัปเดต vX.Y.Z"** ที่แถบด้านบนหน้าขาย และในเมนูด้านซ้าย
   กดปุ่ม → หน้าต่างแสดงเวอร์ชันเก่า → ใหม่ → **อัปเดตตอนนี้** (โปรแกรมปิดแล้วเปิดใหม่เอง) หรือ **ภายหลัง**
   ไม่กดเลย = ติดตั้งให้ตอนปิดโปรแกรม · ไม่ขัดการขายที่ทำอยู่
   เวอร์ชันแอปที่ติดตั้งอยู่ดูได้ที่ท้ายเมนูซ้าย ("แอป 1.0.1")

> ส่วนใหญ่ **ไม่ต้องออกเวอร์ชันแอปใหม่**: หน้าจอ ฟีเจอร์ รายงาน มาจากเซิร์ฟเวอร์ → `pos-update` บน VPS ทุกสาขาได้ทันที
> ต้องออก .exe ใหม่เฉพาะเมื่อแก้ไฟล์ในโฟลเดอร์ `desktop/`

### บังคับอัปเดต (เฉพาะกรณีจำเป็น)
บน VPS:
```bash
echo '{"minVersion":"1.0.1","message":"แก้ปัญหาการพิมพ์ ต้องอัปเดตก่อนใช้งานต่อ"}' > /var/www/pos-updates/min-version.json
```
เครื่องที่เวอร์ชันต่ำกว่า `minVersion` จะไม่มีปุ่ม "ภายหลัง" — ติดตั้งทันทีที่ดาวน์โหลดเสร็จ
ยกเลิก: `rm /var/www/pos-updates/min-version.json`

## ทดลองระหว่างพัฒนา
```bat
cd desktop
npm install
npm start
```
โหมดนี้ไม่ตรวจอัปเดต · ตั้งค่าเครื่องอยู่ที่ `%APPDATA%\Clothing POS\config.json`
