# Clothing POS

ระบบขายหน้าร้าน (Point of Sale) สำหรับร้านเสื้อผ้าหลายสาขา พัฒนาใช้เองภายในร้าน ครอบคลุมงานหน้าร้านและหลังร้าน: ขายสินค้าและพิมพ์ใบเสร็จ สต็อกแยกตามสี/ไซซ์ (SKU) กะการขายและเงินในลิ้นชัก พักบิล ค่าใช้จ่ายร้าน ใบส่งสินค้าจากโรงงานไปสาขา รายงานยอดขายและกำไร และแจ้งเตือนผ่าน LINE / WhatsApp / Webhook

ทุกสาขาใช้ **เซิร์ฟเวอร์กลางเครื่องเดียว** (VPS) รายการสินค้าเหมือนกัน 100% — เพิ่มสินค้าหรือสีที่สาขาหลัก ทุกสาขาเห็นทันที ส่วนสต็อก ราคาขาย บิล และกะ แยกตามสาขา พนักงานเห็นเฉพาะข้อมูลของสาขาตัวเอง ผู้จัดการดูได้ทุกสาขา

หน้าร้านใช้งานผ่าน **แอป Windows (.exe)** ซึ่งเปิดหน้าระบบจากเซิร์ฟเวอร์ พิมพ์ใบเสร็จตรงเข้าเครื่องพิมพ์ (58/80 มม.) และอัปเดตตัวเองผ่านปุ่ม "อัปเดต" ในโปรแกรม เซิร์ฟเวอร์ล็อกให้เข้าได้เฉพาะจากแอปนี้ ตัวติดตั้ง (zip + คู่มือ) สร้างอัตโนมัติด้วย GitHub Actions และดาวน์โหลดได้จากหน้าดาวน์โหลดที่มีรหัสผ่าน

พัฒนาด้วย Expo (React Native Web) + TypeScript ฝั่งเซิร์ฟเวอร์เป็น Node.js + SQLite (`node:sqlite`) และแอปเดสก์ท็อปใช้ Electron — พัฒนาบนเครื่องตัวเองด้วย `npm install` แล้ว `npm run dev:api` กับ `npm run dev` (ใช้ฐานข้อมูลทดลองใน `data/` ห้ามทดสอบบนเซิร์ฟเวอร์จริง) รายละเอียดการติดตั้ง/อัปเดตเซิร์ฟเวอร์อยู่ใน [`deploy/README.md`](deploy/README.md) และแอปเดสก์ท็อปใน [`desktop/README.md`](desktop/README.md)
