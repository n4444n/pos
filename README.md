# POS ร้านเสื้อผ้า v0.3 — หลายสาขา

ระบบ POS (ขายหน้าร้าน) สำหรับร้านเสื้อผ้า — ขาย สต็อก SKU (สี/ไซซ์) กะการขาย ใบเสร็จ รายงาน
พัฒนาด้วย เฟรมเวิร์ค **Expo (React Native Web) + TypeScript** · เซิร์ฟเวอร์ **Node.js (node:sqlite / SQLite)**
**เหมาะสำหรับร้านขายเสื้อผ้าโดยเฉพาะ**

### สิ่งที่แก้ไข

1. **หลายสาขาในเว็บเดียว** — ฐานข้อมูลเดียว แยกสต็อก/ราคา/บิล/กะต่อสาขา, สลับสาขาได้, พนักงานผูกกับสาขาที่ดูแล, เพิ่มสินค้าที่สาขาหลักแล้วทุกสาขาเห็น, หน้าจัดการสาขา
2. **การแจ้งเตือน & API** — LINE (การ์ด Flex ออกแบบเองได้ + ตัวอย่างสด), WhatsApp, Webhook (HMAC) · 10 เหตุการณ์ (ขาย ยกเลิก/แก้บิล สต็อกใกล้หมด/หมด เปิด/ปิดกะ เงินเข้าออก ค่าใช้จ่าย สรุปรายวัน)
3. **ใบเสร็จ** — ภาษาไทย/English/ทั้งสองภาษา, แก้คำในบิลเองได้ทุกคำ, โลโก้หัวบิลปรับขนาดได้, ส่วนท้ายบิลเพิ่มเอง (ข้อความ / QR code / รูปภาพ)
4. **ค่าใช้จ่ายร้าน & เงินในลิ้นชัก** — บันทึกบิลค่าใช้จ่ายหลายรายการ (รายละเอียด หมวด จำนวน/หน่วย ราคา/หน่วย), จ่ายจากลิ้นชักหักกะอัตโนมัติ, สมุดเงินสดในลิ้นชัก, กำไรสุทธิในรายงาน
5. **กะการขาย** — เข้าสู่ระบบแล้วเด้งให้แจงเงินเปิดกะ, แจงธนบัตร/เหรียญแบบใหม่, ปิดกะถามพิมพ์ "สรุปยอดขายประจำวัน" 80mm
6. **พักบิล (Hold)** — พักรายการที่สแกนไว้ให้ลูกค้าไปแลกเงิน ขายคนต่อไปก่อน แล้วเรียกคืนได้ · ย้ายช่องค้นหาบิลมาไว้ในหน้าประวัติการขาย · สาขาย่อยปรับสต็อก/ราคาเองได้

### วิธีการเปิดใช้งานกับ localhost
1. ติดตั้ง Node.js 22.13+
2. `npm install`
3. `npm start` (build หน้าเว็บ + เปิดเซิร์ฟเวอร์ที่ http://localhost:3000)
   - หรือโหมดพัฒนา: `npm run dev:api` และ `npm run dev` (คนละหน้าต่าง)

### วิธีการเปิดใช้งานกับ ngrok
- **Windows:** ดับเบิลคลิก `start-ngrok.bat` (build + เปิดเซิร์ฟเวอร์ + เปิด ngrok + เปิดลิงก์ให้อัตโนมัติ, ลิงก์บันทึกใน `ngrok-url.txt`)
- **หรือสั่งเอง:** `npm start` แล้วเปิดอีกหน้าต่าง `ngrok http 3000` → ใช้ลิงก์ `https://xxxx.ngrok-free.app` ได้ทุกสาขา

# Clothing POS — หน้าขาย (เฟส 1)

ระบบ Point of Sale สำหรับร้านเสื้อผ้า
**Frontend:** React Native (Expo) + TypeScript รันเป็น Web App ผ่าน react-native-web
**Backend:** Node.js (`node:http`) + **SQLite** (`node:sqlite` ในตัว Node — ไม่ต้องติดตั้ง native module)

```
┌──────────── 1 พอร์ต (3000) ────────────┐
│  /            → Web App (expo export)   │  ← ngrok http 3000
│  /api/*       → REST API + SQLite       │
└─────────────────────────────────────────┘
```

## ความต้องการ
- **Node.js 22.13 ขึ้นไป** (แนะนำ Node 24 LTS) — ใช้ `node:sqlite` และรัน TypeScript ฝั่ง server ได้โดยตรง
- ngrok (สมัครฟรีที่ ngrok.com แล้ว `ngrok config add-authtoken <TOKEN>`)

## เริ่มใช้งาน

```bash
npm install
npx expo install --fix      # ปรับเวอร์ชันแพ็กเกจ Expo ให้ตรงกับ SDK ที่ติดตั้ง

npm start                   # build เว็บ + เปิด server ที่ http://localhost:3000
```

### ออนไลน์ด้วย ngrok (เปิดอีกหน้าต่าง terminal)
```bash
npm run tunnel              # = ngrok http 3000
```
นำลิงก์ `https://xxxx.ngrok-free.app` ไปเปิดบนแท็บเล็ต/มือถือได้ทันที
(ครั้งแรก ngrok แบบฟรีจะมีหน้าเตือน ให้กด **Visit Site** หนึ่งครั้ง — ส่วนการเรียก API แอปส่ง header ข้ามหน้าเตือนให้แล้ว)

### โหมดพัฒนา (แก้โค้ดแล้วเห็นผลทันที)
```bash
npm run dev:api     # terminal 1 — API พอร์ต 3000 (auto-reload)
npm run dev         # terminal 2 — Expo web พอร์ต 8081 (hot reload, เรียก API ที่ :3000 อัตโนมัติ)
```
ถ้า API อยู่ที่อื่น ตั้ง `EXPO_PUBLIC_API_URL=https://...` ก่อนรัน

## รายงาน / Dashboard (เมนู ☰ → รายงาน · เฉพาะผู้จัดการ · `/#dashboard`)
- ช่วงเวลา: วันนี้ / เมื่อวาน / 7 วัน / 30 วัน / เดือนนี้ / เดือนที่แล้ว / ปีนี้ / กำหนดเอง — ทุกตัวเลข**เทียบกับช่วงก่อนหน้าที่ยาวเท่ากัน**
- **KPI 4 ใบ**: ยอดขายสุทธิ (+เฉลี่ยต่อบิล) · จำนวนชิ้น (+ชิ้นต่อบิล) · จำนวนบิล (+ยกเลิก/เปลี่ยนสินค้า) · กำไรขั้นต้น (+อัตรากำไร)
- **กราฟ** ยอดขาย / กำไร / บิล / ชิ้น (รายชั่วโมงถ้าเลือก 1 วัน, รายวัน ≤ 62 วัน, รายเดือนถ้านานกว่า) + เส้นประช่วงก่อนหน้า + hover ดูตัวเลข · ปิด/เปิดกราฟได้
- **สินค้าขายดี** (ค้นหาได้) · **ไซซ์ & สีที่ขายดี** · **ยอดขายตามหมวดหมู่**
- **สต็อกใกล้หมด** (เหลือ ≤ 3 เรียงตามความขายดี 30 วัน) + มูลค่าสต็อก
- **ช่วงเวลาที่ขายดี** (ใช้วางกะ) · **ช่องทางชำระเงิน** · **พนักงานขาย** · **คืน/เปลี่ยนสินค้า**
- บิลล่าสุด + ดาวน์โหลดรายงาน CSV
- กำไรขั้นต้น = ยอดขายก่อน VAT − ต้นทุน · ต้นทุนเริ่มต้นตั้งไว้ 45% ของราคาขาย (คอลัมน์ `products.cost` — จะแก้ได้ในหน้าสต็อกสินค้าเฟสถัดไป)

**ทดลองด้วยข้อมูลตัวอย่าง**: `npm run db:demo` สร้างการขายย้อนหลัง 60 วัน (~900 บิล, ทำงานเฉพาะเมื่อยังไม่มีบิล)
ถ้าต้องการเริ่มใหม่: `npm run db:reset` → `npm run db:demo` → `npm run server`

## ความเร็ว & ความเสถียร
- โหลดข้อมูลหน้าขายด้วย **request เดียว** (`/api/bootstrap`) แล้วกรอง/ค้นหาในเครื่อง
- ภาพสินค้าเริ่มต้นเป็นเวกเตอร์ (SVG) ไม่ต้องโหลดรูป — อัปโหลดรูปจริงได้ที่หน้าสต็อก
- SQLite โหมด WAL + prepared statements, API ตอบ ~1–5 ms
- การขายทำใน **transaction** — ตัดสต็อกแบบ atomic (ทดสอบยิง 30 ออเดอร์พร้อมกันบนสินค้าเหลือ 11 ชิ้น → ขายได้ 11 ปฏิเสธ 19 ไม่ติดลบ)
- ราคา/ส่วนลด/VAT คำนวณใหม่ที่ server เสมอ ไม่เชื่อค่าจาก client
- gzip + cache ไฟล์ static แบบ immutable

```
App.tsx                     root + โหลดฟอนต์ไทย

src/screens/StockScreen.tsx หน้าสต็อกสินค้า
src/screens/SkuStockScreen.tsx หน้าสต็อกสินค้า (คุณสมบัติ)
src/components/stock/      ProductEditor, AttributeEditor, SkuMatrix, ImagePicker, Barcode
src/stockDraft.ts           แบบร่างสินค้า/SKU ในหน้าแก้ไข
src/components/             TopBar, CategoryTabs, ProductCard, VariantModal,
                            CartPanel, PaymentModal, ReceiptView, OrdersModal ...
src/store/usePos.ts         state ตะกร้า/ส่วนลด/ชำระเงิน
src/api.ts                  client เรียก API
server/index.ts             HTTP server + API + serve เว็บ
server/db.ts                schema SQLite + ปรับโครงสร้างอัตโนมัติ
server/products.ts          สินค้า/SKU/สต็อก/อัปโหลดรูป
server/seed.ts              ข้อมูลตัวอย่าง 32 สินค้า / 255 SKU
data/pos.db                 ไฟล์ฐานข้อมูล (สร้างอัตโนมัติ)
```
